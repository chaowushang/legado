## 检验范围

逐条检查搜索、详情、目录、两个不同章节，并检查样本编码、目录顺序和翻页规则。剔除仅首页可访问、乱码、目录倒序、误抓推荐列表和超时的候选。每条的时间、规则 SHA-256 与样本统计见 verification.json，不发布正文。

**这是服务器兼容规则引擎抽测，尚未在 Android 阅读客户端实测。** 不等于所有小说、所有章节、所有网络环境都能使用。网页会改版，历史域名和仓库存在多年也不能证明持续可用；本轮没有足够长期观察数据或独立口碑数据来保证稳定性。
