## 导入

下载 `book_sources.json`，在阅读 App → 我的 → 书源管理 → 右上角菜单 → 本地导入，选择文件。

网络导入地址：

```
https://raw.githubusercontent.com/chaowushang/legado/main/book_sources.json
```

网络导入使用“书源管理”，不是“订阅源管理”。

## 后续更新

修改同名 JSON 并提交到 main，链接保持不变。App 再次网络导入同一链接即可获取新版规则。链接本身不会自动修复网站规则；本仓库未设置自动维护或定时更新。
