## 导入顺序

1. 先在书源管理中网络导入[停用旧源文件](https://raw.githubusercontent.com/chaowushang/legado/main/disable_reported_sources.json)，允许覆盖相同书源并检查开关关闭。共 39 条，含用户反馈的37条和本轮其他未通过项。若客户端没有同步停用开关，请在“🚫 停用待复核”组手动关闭。
2. 再网络导入[新版书源](https://raw.githubusercontent.com/chaowushang/legado/main/book_sources.json)。以后沿用此固定链接更新。旧条目不会因从远端JSON移除而必然自动删除；无需删除书架或阅读进度。
