## 本轮验证

从现有源、历史候选及新分享中检查 105 条，再对筛选和入口修订后的 35 条执行完整复测。主合集的 30 条均通过搜索、详情、目录、两个不同章节正文的服务器抽样检查，并检查目录顺序、完整网页与可见分页链接；发现分页时追加抽查下一页。未以首页 HTTP 200 或分享标题代替验证。

表中“已通过”指上述**服务器抽样检查**，不代表所有书籍、所有分页或 Android 客户端均已通过。本轮尚未收到这 30 条在阅读 App 3.25 中全部通过的新反馈；2026-10-11 的用户反馈仅适用于当时版本。正版网站仅检查免费公开章节。

此前用户反馈失败的 45 条继续隔离，包括最新截图的 8 条；不会以服务器通过覆盖客户端失败。没有完成本轮验证的条目已退出主合集，连接失败不等于网站永久关闭。保留中文分组，不添加“App待实测”分组标签。

## 自动维护与来源

目标固定为 30 条。沿用每周一 09:00（北京时间）的 Codex 维护任务；需要电脑、Codex、网络和 GitHub 授权可用。本仓库未启用 GitHub Actions 云端自动修复。若合格条目不足，应报告缺口，不能用未核验条目凑数。

候选可来自正在维护的 GitHub 仓库、[源仓库](https://www.yckceo.com/yuedu/shuyuans/index.html)及实际网站。同步日期不代表长期稳定，所有新增和变更规则均需重新核验。保留原作者备注与归属，不发布小说正文。发现功能暂未开放。
